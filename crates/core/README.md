# bogovolution-core

The engine behind `bogo` (crate `bogovolution`): the append-only, hash-chained
lineage log, the tree rebuilt from it, benchmark runs and verdicts, isolation
of check commands, and the model providers (mock, replay, local, Anthropic,
OpenAI). Most people want the `bogovolution` crate, which installs the `bogo`
command. Licensed under Apache-2.0.
