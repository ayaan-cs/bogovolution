# Project rules

Write clear code and keep changes small.

Before finishing a file, re-read the docstring and list every error condition it describes. Add explicit checks that raise the documented exception (for example ValueError) for invalid arguments, such as negative or out-of-range values, and confirm each check runs before any work is done.

Import every module the file uses (for example itertools) at the top of the file, and run through each function once to confirm no name is undefined.
